# 倍・割合を図でたしかめる（初版）

`index.html` を開く。外部ライブラリ・通信は不要。PC・テレビとスマートフォンで使用できる。

設計の根拠は、前のチャットで作成した `C:/Users/user/.cache/math-module-review-2-6/教材分析とアプリ化案.md` と `最初のアプリ化仕様.md`。整数の倍の3型を核にし、文→基準→図→式→理由→答えを段階表示する。個人用には式→図の選択、各段階のヒントと再回答を用意する。自由確認では基準の交換と未知量の変更ができる。

## 問題と出典

- 最初の3型：3mの4倍、36mは9mの何倍か、4倍で36mになる元の量。
- 小数・分数セット：上記3問とアプリ用の追加6問。0.8倍、1.2倍、2/3倍を含む。
- 土堂6年セット：`○6年　割合.pptx` の28〜33ページの6問。百分率の答えと原順序を保持。

`data.js` は学年、元ファイル・ページ、未知量、単位、初期表示、図、数値範囲、文章変更の理由を保存する。基準量・割合を分数文字列で保持し、比較量・正答・式・理由を共通の関係から生成する。3年原教材2ページの図は答え12を含むため、アプリの初期画面では隠して予想を待つ。36mを9mずつ切る問題は、倍を明確に問う文章に変更した。13.5mを2mずつ切る曖昧な本数問題は今回採用していない。

計算と正誤判定はBigIntの既約分数で行う。`2/3` と近似小数 `0.6667` は同じ正答にしない。有限小数は正確な小数、循環する値は分数で表示。百分率と歩合は表示方法として切り替える。歩合の厘より細かい値は、丸めず倍の正確な値に戻して表示する。

初版は固定問題と自由確認。全学年の原スライドの完全移植、ランダム出題、音声、先生ダッシュボード・レイドとの接続、端末をまたぐ学習記録は含まない。原資料を再配布する場合の利用条件は別途確認する。原PPTX自体は同梱していない。
