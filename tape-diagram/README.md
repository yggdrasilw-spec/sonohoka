# おはなしを 図にしよう

`index.html` をブラウザで開くと利用できます。インターネット接続・ビルド・外部ライブラリは不要です。端末の音声合成が使える場合は「お話をきく」で読み上げられます。

## 学習の流れ

最初に「なぜテープ図？」の５場面を表示します。花8本と7本で○図のよさを確かめ、38本と17本の○を１つずつ描く手間を体験します。５こ描いた後は次へ進めるので、55回の操作を強制しません。55この○を見て負担を振り返り、そのまとまりが数を書いた２本のテープに変わる様子を確認します。２本をつないで全体を示した後、同じ問題のテープを描く練習に入ります。上部の「なぜテープ図？」で導入をやり直せます。

○図のよさを否定せず、「数が多くても、数量とまとまりの関係を少ない線で表せる」というテープ図の必要性を導入します。

数量が表す「ここからここまで」の範囲は弧で示します。部分は下側の弧、全体は上側の弧で示し、導入・○図・テープ図で同じ表し方にそろえています。

## 線分図・割合・比への発展

お話の図の「名前と数」「式」では、同じ図をテープ図と線分図で切り替えられます。両端・境界・弧・数量はそのままで、テープの幅だけをなくします。式の確認後は「この図から 割合・比へ」で、今のお話の数量を使った移行を見られます。上部の「線分図・割合・比」からも開けます。

- 線分図への移行：全体と部分、または比較の２本の図について、テープの幅をなくす前後を比較。
- 割合：上の線が数量、下の線が割合。同じ横位置を対応線で結び、もとにする量を1（100％）と見る。40％・100％・150％の例、基準の入替、割合・くらべる量・もとにする量の３通りの未知数に対応。
- 比：同じ１つ分を共通の長さとして２本を表す。2：3に30こを分ける例なら、全部は5こ分、1つ分は6こ、各部分は12こ・18こ。テープと線分を切替可能。

割合と比の画面で数値・単位・未知の場所を変更できます。割合はもとにする量1〜1000、くらべる量0〜2000。比は各1〜10、全体1〜1000で、１つ分が整数になる数に限ります。小数が続く割合は４桁まで表示し「約」を付けます。発展の数値設定は現在の画面内で保持し、元の「お話の設定」のJSON保存とは別です。

割合の２本は異なる尺度（数量と割合）を対応させる図です。比の２本は同じ尺度で、同じ長さの１つ分を共有する図です。割合や比の長さは数値に比例させ、テープ導入の最小幅補正は使いません。

`extension-engine.js` の `percent(data)`・`ratio(data)` は計算と入力検証を担当し、`extension.js` は発展の表示と操作を担当します。２年生の導入は従来どおり最初に表示され、発展画面へはボタンで進みます。

## 図をつくる６つの練習

上部の「図を つくる練習」から、１画面１課題の練習へ進めます。元のお話の先生設定を使って作ったカスタム問題も、その教材から練習を開くと使えます。

|練習|操作と確かめること|
|---|---|
|お話と図をむすぶ|名前と数のボタンを選び、対応する弧に置く。３つの数量の範囲を確認|
|□の場所をかえる|同じ図の全体・左・右を未知に切り替え、たし算／ひき算を選ぶ。お話も未知の場所に合わせて再生成|
|まちがった図を直す|入れ違った名前と数を、２回のタッチで交換。全体と部分の対応を判定|
|自分で図をつくる|描き始める場所を選ぶ。指で描いて接続・分割・比較を行い、最後に弧へ名前と数を配置|
|図からお話をつくる|合併・増加・減少・比較を選び、図に合う文章を書く。書き出しの支援、文章の保存|
|図の表し方をえらぶ|○・テープ・線分を切り替え、選んだ理由を書く。連続量では○の個数への置換を案内しない|

描画の支援は「なぞる」「始点だけ」「白紙から」の３段階です。「ヒント」と「お手本といっしょに描く」はいつでも使えます。描画の判定は、左から右へ描くこと、図の中での分割、部分の接続、比較の左端の一致と大小です。正確な縮尺や手書き文字の認識は行いません。配置済みの名前と数について、全体・部分の対応を検証します。

お話づくりと図を選んだ理由は、内容を自動採点しません。先生や友だちと図の数・名前・関係を読み合わせる活動です。独自の文章の意味を自動解析せず、問題モデルの名前と数量を使って練習します。

「図を保存」で現在の図を、スタイルを含む単体SVGに書き出します。「図を印刷」は現在の問題・図・文章を印刷する表示です。練習記録は端末のlocalStorageへ直近100件を保存し、練習メニューの先生用記録からJSONへ書き出せます。記録には練習の種類、問題名、支援段階、ヒント・お手本の使用回数、確認結果、自作文章または理由を含めます。件数は提出・確認の記録で、習熟度を自動判定する点数ではありません。

`workshop-engine.js` は配置と描画の検証、`workshop.js` は６種類の練習・保存・出力を担当します。

お話 → 動き → 絵を１つずつ○に置換 → ○図 → 描き始める場所の選択 → テープを描く → 接続・分割 → 名前と数 → 全体と部分から式を決定。

- 合併：２つのまとまりをつなぐ。
- 増加：はじめの数は左の部分。そこから増えた部分をつなぐ。
- 減少：はじめの数は全体。全体を描いてから、出ていった部分とのこりに分ける。○図でははじめの○を残し、出ていった分に斜線を入れる。
- 比較：２本のテープを同じ左端から描く。対応しない部分が差。

式は「ふえる」「へる」という語ではなく、未知の場所で決めます。全体が未知なら部分＋部分、部分が未知なら全体−既知部分です。未知のまとまりの絵は個数を示さず「？」にします。既知の全体を分けたり、既知の２列を対応させたりする○図では、図から未知数を数えて考えられます。

## お話の差し替え

画面の「先生の設定」で種類・左右の部分の数・未知の場所・単位・絵文字・画像・名前・文章を変更できます。画像はPNG/JPEG/WebP/GIFを１枚1MBまで。設定をJSONで保存・読込できます。作ったお話は端末のlocalStorageにも保存します。

空欄の文章は自動生成します。文章を独自に書く場合は、数値や未知の場所を設定と一致させてください。文章の意味の自動解析は行いません。数値を変更した後、既存の文章も変更するか、空欄にしてください。

```js
{
  id: 'custom', kind: 'increase', title: 'りんごを もらった',
  left: 5, right: 3, unknown: 'total', unit: 'こ',
  iconA: '🍎', iconB: '🍎', nameA: 'はじめ', nameB: 'もらった',
  story: ['りんごが はじめに 5こ ありました。', '3こ もらいました。', 'ぜんぶで 何こでしょう。']
}
```

`kind` は `combine/increase/decrease/compare`。`unknown` は `left/right/total`。`total` は `left + right` から計算します。比較では `left` が少ない数、`right` が差、`total` が多い数です。`continuous: true` または設定の単位 `m/cm` では、リボンなど連続量を○にせず長さからテープへ進めます。

`engine.js` は表示と独立したモデル・入力検証・演算選択です。ブラウザの `TapeLessonEngine.model(data)` とNode.jsの `require('./engine.js')` で再利用できます。`lessons.js` は問題データ、`app.js` は段階と操作、`style.css` は表示です。別の教材でも問題データを差し替えられます。

テープ長は数量関係をつかむための目安です。部分の大小を保って表示し、とても短い部分はタッチ操作のため最小幅を設けています。縮尺を測って答えを求める教材ではありません。図のラベルで数量と役割を確かめてください。先生と１場面ずつ進める導入教材で、自由描画の形を採点する機能はありません。

## 提供資料との対応

提供された「２年算数たし算とひき算 (1).pptx」22枚を読み取り、操作できる教材へ再構成しました。PPTXの効果・タイミング・配置を完全に複製するものではありません。

|資料|教材|
|---|---|
|2〜4枚|花8本と7本、絵から○|
|5〜14枚|花38本と17本、○からテープ、接続、名前と数量|
|15枚|みかん15こ、全部32こ、買った数が未知|
|16枚|配ったジュース26本、残り8本、はじめが未知|
|17・20枚|来た8人、全部23人、はじめが未知|
|18枚|リボン12m、残り5m、使った長さが未知|
|19枚|はじめ30人、残り12人、帰った数が未知|
|21枚|はじめ28こ、全部50こ、買った数が未知|
|22枚|配った花15本、残り9本、はじめが未知|

数が増えたときに○を大量に描く負担を体験してから、テープの利点を確かめられます。資料7〜9枚の十の束・筆算への寄り道は、本教材では○とテープの関係に焦点を絞るため収録していません。小さい数の増加・減少・比較は追加の導入問題です。

`assets/red-flower.png` と `assets/white-flower.png` は提供資料の `ppt/media/image2.png` と `image1.png` から取り出した画像です。元画像の権利・利用条件は資料側に従います。出典を推測してライセンスを付けていません。

## 検証

`node scripts/qa-tape-diagram.cjs` で、１２問題の学習手順、式、未知の数の扱い、描画操作、設定入出力、画像差替え、画面幅を検証します。スクリーンショットはユーザーキャッシュに保存します。

`node scripts/qa-tape-extension.cjs` は線分図・割合・比、`node scripts/qa-tape-workshop.cjs` は６つの練習・白紙からの描画・誤った配置や接続の拒否・SVG出力・記録の保存・モバイル表示を検証します。
