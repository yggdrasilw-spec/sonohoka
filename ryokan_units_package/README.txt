たんいをえらぼう 画像刷新版

対象：小学2〜4年生

■ 内容
- index.html : 実行用HTML
- data/questions.json : 問題データ（全66問）
- img/questions/ : 問題画面用画像（答えの単位を表示しない）
- img/explanations/ : 答え合わせ用画像（正しい量＋1単位の基準）
- img/unit_refs/ : 1mm / 1cm / 1m / 1km / 1mL / 1dL / 1L / 1g / 1kg の量感カード
- img/source_sheets/ : 今回生成した元シート（再編集用）
- 現在の画面では、元シートのカードをSVGの表示範囲とクリップで直接表示します。以前のWebPの切り出しによる見切れを避け、解説も同じイラストと単位のめやすを使います。

■ 問題数
- ながさ: 18問
- かさ: 11問
- おもさ: 15問（g・kg・t）
- きょり: 10問
- 時間（2年）: 6問（分・時間）
- 面積（4年）: 6問（cm²・m²・a・ha・km²）
- 合計: 66問
- 効果音: 選択・正解・不正解・次へ。音ON/OFFの設定はブラウザに保存。
- img/generated/ : 時間・重さ・面積・ランニングの追加イラスト。数字や単位を入れず、問題の答えが絵から見えない構成。
- img/generated/prompts.json : built-in image_genで使用した生成プロンプト。
- img/generated/prompts-v2.json : 2026-10-08に生成した専用画像10点のプロンプト。
- 時間6問はそれぞれ専用の場面画像を使用します。授業・休み時間・学校で過ごす一日、給食の準備と食事を区別しています。
- 面積は10aの田んぼ、100m四方の1haの田んぼ全体、集落・田畑・川・山を含む村の広域空撮を別画像にしています。

■ 1mmの基準
「少し使った普通のHBえんぴつの、芯の先部分の太さ」を基準にしています。
専用の拡大画像で芯の先の太さを示します。以前の「あつさ」を含む基準カードは表示しません。

■ 1mの基準
「床から2年生の首のあたりまで」を目安として扱います。

■ 起動
index.html をブラウザで開いてください。GitHub Pagesにもそのまま配置できます。
