🌱 さんすうステップ

わからなくなったところから、小さな一歩ずつ。小学校の算数を学び直すためのアプリです。中学生以降の学び直しにも使えるよう、内容から選べる入口を用意しています。

できること

  • 小1〜小6の目安と7系統から選べる、281内容のマップ。
  • 短い診断から関連する基礎へ戻り、練習後に元の内容へ進む。
  • 図と段階的な解説で確かめる。分数、ものさし、かさの図にも対応。
  • 最大6問のおすすめコースと、日を置いた復習。
  • 学習記録は利用するPCに保存。文字サイズと動きの設定も選べる。

今の提供形態

現在はPythonで起動するPC用のローカル版です。このページからブラウザだけで学習を始める公開版は準備中です。全概念の課題入口がありますが、作図・自由な説明の評価や診断精度の検証は開発を続けています。

起動方法（Windows）

Python 3.14とGitを用意し、アクセス権のあるGitHubアカウントでリポジトリを取得します。リポジトリは現在非公開です。

git clone https://github.com/yggdrasilw-spec/shogakusansuDB.git
cd shogakusansuDB
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m scripts.relearning_app

起動後に、同じPCのブラウザで以下のボタンを開いてください。終了は起動したターミナルで Ctrl+C。次回は最後の起動コマンドだけで使えます。

起動済みのアプリを開く

学習記録はリポジトリ内の .local/relearning/ に保存します。GitHubには送信しません。
