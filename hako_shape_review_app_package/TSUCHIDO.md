# 土堂「箱をつくれるかな」の取り込み

前のチャットの `最初のアプリ化仕様.md` 案Aに沿って、既存の面・辺・頂点の復習を残し、「土堂の25もん」を追加した。独立入口は `hako_shape_review_app.html?activity=tsuchido`。

出典は提供された `○2年 はこの形.pptx`（表紙1枚、問題25枚）。問題の原順序、形の寸法比・位置・色、解答の○×を取り込んだ。前半9問は離れた面の組、後半16問はつながった面の配置。繰り返しの問題も原順序で残している。

`scripts/import-tsuchido-hako.py` は原PPTXのDrawingML図形と解答マークを読み取り、`tsuchido-hako-data.js` を生成する。元資料の答えマークは問題画面には描画しない。出典とページは毎問表示する。原PPTXは変更・同梱していない。

○×を予想してから確認する。誤答時は部分的なヒントで再回答。教師用は解答を手動表示。成立する面の組は対応辺をつないだ展開図に移し、折って確認できる。成立しない組は不足・過剰・形の不一致を説明する。後半は全問題で元の配置を折りたたみ作業台へ移し、停止・逆戻し・回転・自由配置ができる。

原19・24ページの1面の位置には約0.0063辺分のずれがある。出題図は元の座標を保持し、折りたたみ時だけ最寄りの正方形格子へ丸め、意図された辺の接続を再現する。答えは原○×と立体幾何の両方で照合する。

成立しない面の組への組み立てアニメーションと理由選択は今後の拡張。今回の判定理由は問題に応じて数・同じ形の組・折った後の重なりを分けている。原資料の外部公開・改変条件は別途確認する。
