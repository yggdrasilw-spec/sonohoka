# つなぎ言葉アプリ v3（挿絵28問 完成版）

## 収録内容
- 順接（理由→結果）：10問
- 逆接：10問
- つけ足し・並列：8問
- 合計：28問

全28問の挿絵を `img/` にWebPで収録しています。
画像はすべて **960×540（16:9） / WebP quality 80** に統一しています。

`index.html` を開くと、そのまま教材として使用できます。
画像が読み込めない場合は、HTML内の場面カードへ自動フォールバックします。
