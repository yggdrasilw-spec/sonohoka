# くちの おとラボ

3年生のローマ字学習に先立つ、アルファベットと口の音の教材。静的HTMLアプリです。

## 学習の流れ

1. 大文字・小文字と文字の名前。a・gなどを3種類の書体で比較します。
2. 英語の代表的な30音。各音に3〜4個の身近な単語と絵を掲載し、対応する綴りに色を付けます。
3. 日本語の「あ・い・う・え・お」。英語の短母音とは区別します。
4. m・k・n・pと5母音を近づけ、20個のひらがなの音を試します。表は導入用の一部です。

## 起動と録音

`index.html`で学習画面を開けます。直接録音する場合はHTTPSまたはlocalhostで配信してください。Pythonを使う場合は、このフォルダーで `python -m http.server 8966 --bind 127.0.0.1` を実行し、ブラウザーで `http://localhost:8966/` を開きます。

「先生の声を入れる」で対象を選び、「録音する」→「止めて保存」。既存の音声ファイルも登録できます。初期状態には音声を入れていません。自動音声の代用はありません。

録音はそのブラウザーのIndexedDBに保存され、サーバーに送信されません。「録音をまとめて保存」でJSONバックアップを作り、別端末の「保存した録音を読み込む」で移せます。同じ対象を読み込むと置き換わります。ブラウザーのデータ削除、別のURL・ポートへの移動時はバックアップを使用してください。

音をつなぐ録音は「離す」「近づける」「つなぐ」の3種類。「つなぐ」は自然な日本語の音をそのまま実演します。録音を機械的に接合しません。p・t・kは伸ばさず、余分な「ウ」を添えません。

## 図と素材

口の図は、舌・唇・歯の関係と息の方向を示す導入用の簡略図です。先生の実演と併用してください。声の有無は画面の表示と、のどにそっと手を添える体験で確認します。英語のrと日本語のら行は区別します。

絵はこの教材用に画像生成で新規作成しました。添付PowerPointの図やロゴを流用していません。生成の仕様と出典は [assets/README.md](assets/README.md) に記録しています。書体比較の実際の表示は端末のフォントに依存します。

## 編集

- `data.js`：単語、対応する綴り、口の動き、母音、ローマ字表
- `app.js`：学習操作、録音、保存・バックアップ
- `style.css`：画面と書体
- `assets/words` / `assets/mouths`：WebP画像

外部ライブラリーや通信を必要としない構成です。発音参照へのリンクのみ別ページを開きます。
