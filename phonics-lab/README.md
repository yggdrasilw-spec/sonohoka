# くちの おとラボ

3年生のローマ字学習に先立つ、アルファベットと口の音の教材。静的HTMLアプリです。

## 学習の流れ

1. 大文字・小文字と文字の名前。a・gなどを3種類の書体で比較します。
2. 英語の代表的な30音。各音に3〜4個の身近な単語と絵を掲載し、対応する綴りに色を付けます。
3. 日本語の「あ・い・う・え・お」。英語の短母音とは区別します。
4. m・k・n・pと5母音を近づけ、20個のひらがなの音を試します。表は導入用の一部です。

「英語を読んでみよう」では、使う音を選ぶと24語のうち試せる単語の数が増えます。最初はb・a・tでbat、mを追加してmat。音の部品を押して聞き、単語全体を自分で読んでから絵と意味を開きます。表示する数は選択した音に対応する単語の数で、習熟度の自動判定ではありません。音の選択はブラウザーに保存します。

「次のきまり」ではmoonのoo、snakeのa…eを扱い、「特別な読み方」ではwatchとoneを扱います。「この30音さえ完璧なら何でも読める」という説明にはしていません。文字と音の対応を増やし、例外の部分を確かめながら読む構成です。

追加の単語とoo・a…eの音も「先生の声を入れる」の一覧から録音できます。既存の単語の録音はそのまま使います。

## 起動と録音

`index.html`で学習画面を開けます。直接録音する場合はHTTPSまたはlocalhostで配信してください。Pythonを使う場合は、このフォルダーで `python -m http.server 8966 --bind 127.0.0.1` を実行し、ブラウザーで `http://localhost:8966/` を開きます。

標準音声148件を同梱しています。Google Cloud Text-to-Speechの英語（米国）Neural2-F、日本語Neural2-Bで事前生成したMP3で、授業中にAPI通信は行いません。文字名26件、単語97件、日本語母音5件、つないだ日本語20件です。英語の単音32件（oo・a…eを含む）は先生の録音待ちです。単語の読み上げを単音の代わりには使いません。

画面右上の「音声を確認」で全220対象を一覧できます。標準音声と先生の声を別々に聞き、「未確認・確認済み・差し替えたい」を記録します。種類・確認状況で絞り込み、気になる音の「録音・差し替え」から録音画面へ移れます。再生だけでは確認済みになりません。確認状況はブラウザーのlocalStorageに保存し、録音バックアップには含めません。

「先生の声を入れる」で対象を選び、「録音する」→「止めて保存」。既存の音声ファイルも登録できます。先生の録音がある対象は、標準音声より優先します。「標準と聞き比べる」で元の音を確認でき、「この録音を削除する」で標準に戻せます。標準のない対象は録音待ちに戻ります。英語の単音32件と日本語の「離す・近づける」40件は先生の実演用です。

録音はそのブラウザーのIndexedDBに保存され、サーバーに送信されません。「録音をまとめて保存」でJSONバックアップを作り、別端末の「保存した録音を読み込む」で移せます。同じ対象を読み込むと置き換わります。ブラウザーのデータ削除、別のURL・ポートへの移動時はバックアップを使用してください。

音をつなぐ録音は「離す」「近づける」「つなぐ」の3種類。「つなぐ」は自然な日本語の音をそのまま実演します。録音を機械的に接合しません。p・t・kは伸ばさず、余分な「ウ」を添えません。

## 単語から切り出した音の試聴

「音声を確認」から [切り出し音の試聴](audio-candidates.html) を開けます。既存の単語音声から32音を切り出した候補です。単音の生成に失敗した従来の32ファイルとは別で、学習画面には自動では採用しません。

元の単語と候補を聞き比べ、波形を見ながら開始・終了を調整できます。「この音をおとラボで使う」で、その音だけをブラウザーのIndexedDBへ登録します。既存の録音がある場合はボタンに置き換える旨を表示します。採用した切り出し音より、後から録音した声を優先できます。WAVのダウンロードと確認メモのJSON保存もできます。

切る位置は波形・スペクトログラムを見て設定した初期候補です。周囲の音の影響や、境目を切ることで失う手がかりがあるため、発音教材としての最終確認は試聴で行います。特に短い破裂音、l・r・w・y、複合音は重点確認してください。切り出し音は伸長・ループせず、最大12dBの音量調整、端の1msフェード、前30ms・後250msの無音だけを加えています。

再作成はリポジトリ直下で `python scripts/cut-phonics-audio.py`（numpy、imageio-ffmpegが必要）。切り出す単語・秒位置と処理は `assets/audio-candidates/manifest.json` に保存します。位置調整と直接登録にはlocalhostまたはHTTPSで開いてください。

## 図と素材

口の図は、舌・唇・歯の関係と息の方向を示す導入用の簡略図です。先生の実演と併用してください。声の有無は画面の表示と、のどにそっと手を添える体験で確認します。英語のrと日本語のら行は区別します。

絵はこの教材用に画像生成で新規作成しました。添付PowerPointの図やロゴを流用していません。生成の仕様と出典は [assets/README.md](assets/README.md) に記録しています。書体比較の実際の表示は端末のフォントに依存します。

## 編集

- `data.js`：単語、対応する綴り、口の動き、母音、ローマ字表
- `app.js`：学習操作、録音、保存・バックアップ
- `style.css`：画面と書体
- `reading-data.js` / `reading.js`：読む単語の音分け、音を選ぶ体験、絵・意味の開示
- `assets/words` / `assets/mouths`：WebP画像

外部ライブラリーや外部APIへの通信を必要としない構成です。MP3は同じサイトから読み込みます。発音参照へのリンクのみ別ページを開きます。

## 標準音声の再生成

`node scripts/generate-phonics-audio.cjs --dry-run`で対象とSSMLを確認できます。Google Cloudの課金設定済みプロジェクトでCloud Text-to-Speech APIを有効にし、`gcloud auth login`済みの環境で `node scripts/generate-phonics-audio.cjs` を実行します。既存のgcloudプロジェクトを使い、`GOOGLE_CLOUD_PROJECT`で変更できます。API利用料金が発生します。

`--only=letter:s`で1件、`--limit=3`で先頭3件を生成できます。同じ声・SSMLの生成済みファイルは再利用します。生成後に `assets/audio/manifest.json`（声・SSML・生成日時）と `audio-data.js` を更新します。認証情報は保存しません。

SSMLの`phoneme`は単語の発音指定です。Googleの仕様では音節に母音を含める必要があり、子音1つの指定は元の単語や文字名へ戻ることがありました。Neural2・WaveNet・Chirp 3 HDで試作し、指示対応Gemini-TTSでも余分な母音や文字名になる出力を確認したため、未検証の単音は同梱しません。従来の単音32ファイルは誤って単語が鳴るため撤去しました。文字名は`say-as interpret-as="characters"`で生成します。録音時は子音の後に余計な母音が付いていないか、短い破裂音が欠けていないか、英語の母音と日本語の母音の区別を、実際に聞いて確認してください。「離す・近づける」は機械的に接合せず、実演を録音します。

- [Googleの対応音素](https://docs.cloud.google.com/text-to-speech/docs/phonemes)
- [Googleの音声一覧](https://docs.cloud.google.com/text-to-speech/docs/list-voices-and-types)
