# せいかつカレンダー

GitHub Pages などの静的Webサーバーで `index.html` を開いて使う、先生端末向けの生活カレンダーです。行事データは localStorage、先生が追加した写真は IndexedDB にだけ保存され、外部へ送信されません。

## 画像ライブラリの追加

別プロジェクトで生成した PNG / WebP を `images/library/カテゴリ/` に置き、`images/manifest.json` に `id`、`category`、`label`、`path` を追加してください。`id` は行事の段階が参照する画像IDです。

初期状態の `manifest.json` は、生成予定素材の登録例です。画像ファイルを追加するまで、アプリは写真部分を空欄として表示します。先生が画面からアップロードした画像はこのフォルダに保存されず、端末内の IndexedDB に保存されます。

## バックアップ

「バックアップを書き出す」で行事データとアップロード済み画像を1つの JSON ファイルに保存できます。ブラウザのデータ消去や端末交換の前に、必ず安全な場所へ保管してください。
