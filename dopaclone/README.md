# かずの芽ラボ — 学校・横長版

小学1〜6年の算数計算を扱う、ブラウザだけで動く学習ドリルです。Chromebook等の16:9横長画面では「キャラクター／問題／入力」の3カラムで表示し、学校向けモードでは速度競争や収集要素を前面に出さず、問題・復習・段階ヒントを中心にします。

## 主な特徴

- 小学1〜6年の計算58スキルと前提関係を持つスキルツリー
- 「じぶんレベル」による簡易プレイスメントと、最近の成績を使う習熟判定
- 誤答した問題の保存・復習、時間を空けた再確認、タイムカプセル問題
- 誤答回数に応じた段階ヒントと、オリジナル学習マスコットによる指差し・表情・リアクション
- 16:9横長レイアウト、キーボード入力、動きの強さ、音量、`prefers-reduced-motion` 対応
- 記録は既定で端末内の `localStorage` に保存し、外部送信なし
- 学習ロジックの自動テストを同梱

## ブランドとアセット

この学校版では、元プロジェクトの保護対象だった名称・ロゴ・マスコット造形をアプリから削除し、以下を新規作成しています。

- 名称：**かずの芽ラボ**
- ロゴ：`app/kazunome-logo.svg`（本＋電球のオリジナルSVG）
- アプリアイコン：`app/kazunome-icon.svg`
- 学習マスコット：芽＋えんぴつをモチーフにしたオリジナルSVG。基準図は `docs/mascot.svg`
- 背景内のキャラクターシルエット：汎用のきらめき形状へ変更
- 着せ替えSVG：新マスコットの座標系に合わせて新規描画

## 起動

ビルドは不要です。`app/` を静的配信します。

```bash
python3 -m http.server 8000 -d app
```

ブラウザで `http://localhost:8000/` を開きます。ES Modulesのため `file://` 直開きは非対応です。

## テスト

Node.js 20以上：

```bash
node --test tests/*.test.mjs
```

基盤コードは `LICENSE` に記載されたMIT Licenseのコードを改変しています。そのため元著作権表示とMITライセンス文は保持しています。元プロジェクトの名称・ロゴ・マスコット等はMIT対象外ですが、この版の配布物ではそれらの旧アセットを使用していません。詳細は `NOTICE.md` と `LICENSE` を参照してください。
