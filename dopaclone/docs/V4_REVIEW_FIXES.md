# v4 敵対的レビュー対応

## 今回直したもの

- ブランド名を仮称「かずの芽ラボ」へ変更。
- ロゴは文字をアウトライン化したSVG。外部フォント依存なし。
- アイコン／ロゴのファイル名も旧ブランドから分離。
- `mascot.js` は新キャラクター専用としてゼロから再構築。旧v3実装との完全一致非コメント行は約11%。
- 学校モードでは、コンボ、クエスト、ログインボーナス、トロフィー、エクストラを処理レベルで停止。
- 学校モードの誤答は「キャラが傷つく」演出を廃止し、軽い再試行＋段階ヒントへ変更。
- 学校モード用の星評価を追加。速度は条件に含めず、正確性・安定性・保持を評価。
- 結果画面では学校モード時に点数・タイム・ひらめき値を非表示。
- 成長比較／タイムカプセルでも学校モード時は速度比較を表示しない。
- 横長の筆算フィットを `clientHeight` 基準に修正。
- 1〜2年では一部の固定表現をひらがな・数字表記へ自動変換。
- Web Speech API を使う問題読み上げボタンを追加。
- `user-scalable=no` を削除し、ブラウザ拡大を許可。
- `?mode=school` または `?school` で学校モードを固定し、児童側の切替UIを隠す。
- 学校モード初期の動きは保存値がない場合35%に抑制。

## URL例

`index.html?mode=school`

教師が設定済みURLを配布する運用では、ここへ `count` 等の既存URL設定を組み合わせられる。

## ブランド名について

「かずの芽ラボ」は今回の作業用仮称。一般Web検索では完全一致の教育アプリ名は確認できなかったが、商標・法人名・未インデックスのサービスを網羅した正式なクリアランスではない。公開ブランド確定時は別途確認する。
