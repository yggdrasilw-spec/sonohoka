# v6 横長UI再設計

## 対象
- 1366×768 Chromebook / PC
- 1024×600前後の低い横長画面
- 学校モードを標準とする

## 初期画面
- 左：ブランド＋大きなマスコット領域
- 右：開始操作を1枚の大きな操作カードへ集約
- 「おすすめから はじめる」を最重要ボタンとして全幅化
- 学年1〜6を横一列に配置
- 「できることを見る」を全幅の補助導線に変更
- 設定／ヘルプは右上に横並び

## プレイ画面
- 左：マスコット＋正誤状況
- 中央：問題を最大化
- 右：大型テンキー
- 1366×768ではテンキー1キー約78px高を基準
- 横長時はマスコットの実スケール上限も引き上げる

## 設定
- 横長時は2カラム
- 問題数・音・読み上げ・動き・デモ・データをカード状に配置
- 閉じるボタンを下部中央に大きく固定

## 初回ガイド
- 横長時は幅560pxを上限とする説明カード
- 戻る／次へボタンは58px高

## 結果画面
- 横長時はアクションを2列グリッド化
- 学校モードでは速度表示をCSSでも非表示にする

## 検証
- 1366×768静的レイアウトレンダリング
- 1024×600静的レイアウトレンダリング
- 既存テスト＋横長UIテスト 75/75 通過
