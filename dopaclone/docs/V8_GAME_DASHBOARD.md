# v8 ゲームモード横長ダッシュボード修正

ゲームモードでは学校モードより常設情報が多く、v7の2カラム構成では
ミッションとカレンダーが下方向へ押し出される問題がありました。

## 修正
- 横長ゲームモード専用の3カラム構成を追加
  - 左: ロゴ + マスコット
  - 中央: おすすめ / 学年 / コレクション等の開始操作
  - 右上: ミッション
  - 右下: カレンダー
- 1366x768級ではスクロールせずカレンダーを表示
- 1024x600級では各カードと学年ボタンを圧縮し、カレンダーを画面内に維持
- 学校モードでは従来通りミッション・カレンダーを非表示
- 回帰テスト `app_game_dashboard.test.mjs` を追加
