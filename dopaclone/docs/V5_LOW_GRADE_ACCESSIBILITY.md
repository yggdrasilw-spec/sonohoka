# v5: 低学年・読み上げ・独立ブランド仕上げ

敵対的レビュー項目 7〜13 を仕上げた版。

## 7. 1・2年生向けUI
- 問題タイトル・問題番号・位の名前・結果・設定・スキルツリーの主要文言を低学年表記へ切替。
- 1・2年の問題では `low-grade` クラスを自動付与し、文字サイズと行間も少し拡大。
- `?grade=1` / `?grade=2` を付けた学校URLでは、タイトル画面から低学年表記を使える。
- 動的なスキル名や結果文言にも `learnerText()` を通す。

## 8. 読み上げ
- 問題カードの 🔊 でいつでも手動読み上げ。
- 設定に「読み上げ」を追加し、自動読み上げを任意でONにできる。
- 自動読み上げは問題開始時と次の入力ステップへ移った時に短く案内する。
- 設定は localStorage に保存する。
- Web Speech API 非対応環境では読み上げUIを隠す。

## 9. ブラウザ拡大
- `user-scalable=no` を使用しない。
- viewport の不要な末尾カンマも修正。

## 10. ロゴ
- `app/kazunome-logo.svg` の文字は `<text>` ではなくSVGパス。
- 端末フォントに依存しない。

## 12. マスコット実装

- 葉の動きは `leafL` / `leafR` として扱い、旧身体部位名を撤去。
- 初回ガイドも新Spring名へ修正。

## 13. 学校URL固定
- `?mode=school` または `?school` で学校モード固定。
- 固定URLでは切替設定自体を非表示にし、通常setterからOFFにできない。
