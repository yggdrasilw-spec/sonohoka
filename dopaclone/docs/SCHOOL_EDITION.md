# 学校・横長版 設計メモ

この版は元のゲーム性を削除せず、学校利用時だけ学習タスクを前面に出すフォークです。

## 実装済み

- 760px以上の横長画面で、最大460pxの縦型制約を解除。
- プレイ画面を「左：キャラクター／中央：問題／右：テンキー」の3カラムへ変更。
- タイトル画面も横長ダッシュボード化。
- `schoolMode` を設定として保存し、初期値をON。
- 学校向けでは速度表示・コンボ・ひらめき値・ログイン系UI・収集UI・エクストラ導線を前面から外す。
- 誤答表示を「おしい」ではなく「もういちど」に変更。
- 元の機能はコードから削除せず、設定で「ゲーム向け」へ戻せる。
- `prefers-reduced-motion` と既存の動き調整は維持。

## 他教材へ輸入価値が高い仕組み

1. 誤答回数に応じた段階ヒント（注目箇所→言語ヒント）。
2. 誤答した問題そのものを保存して復習する仕組み。
3. 最近の複数問を使う習熟判定。
4. 習得後の時間経過を見て再確認する仕組み。
5. 前提関係を持つスキルグラフ。
6. 自動デモ。
7. 動きの強さ・音量・キーボード操作などのアクセシビリティ。
8. 学習ロジックの単体テスト。

## 次の共通基盤候補

各教材で次の学習状態を共通形式にする。

```js
{
  concept: 0,      // 意味理解
  procedure: 0,    // 手順
  independence: 0, // 自力
  fluency: 0,      // 流暢性（必要な教材のみ）
  retention: 0     // 時間を空けた保持
}
```

誤答ログは正誤だけでなく `errorType` と `hintLevelReached` を保存し、Firebaseの先生コード利用時には必要な授業中情報だけを一時同期する。

## ブランド差し替えとライセンス

元プロジェクトの名称・ロゴ・マスコット造形はこの版のアプリから削除し、名称、ロゴ、アイコン、マスコット、背景シルエット、着せ替えSVGを新規のものへ差し替えています。基盤コードのMIT著作権表示は `LICENSE` に保持します。配布物の由来は `NOTICE.md` に整理しています。

## v5 低学年・アクセシビリティ
- 1・2年生の問題では主要UIをひらがな中心へ切替。
- 🔊手動読み上げ＋任意の自動読み上げ設定を追加。
- 学校配布URL例: `index.html?mode=school&grade=2`
- ブラウザ標準の拡大操作を禁止しない。
