# かなの かたち研究室（作品集用コピー）

元の開発先は hiragana-ninshiki。直接改修せず、元を更新して `node scripts/sync-kana-feedback-lab.cjs` で同期します。元のHEAD・未コミット状態・各ファイルのSHA-256は `_SOURCE.json` に記録しています。

対象は「く・し・つ・り・こ・き」の６文字。助言の比較・人手レビュー用の試作で、字形の正誤判定は未実装です。
