# そのほか — 学習アプリ集

算数・国語・図形・生活科などのブラウザ学習アプリをまとめたリポジトリです。公開中のアプリ一覧は [`app_links_portfolio.html`](app_links_portfolio.html)、各アプリは同ファイル内の「開く」リンクから利用できます。

## 使い方

単体HTMLはブラウザで開いてください。`fetch()` で別ファイルやデータを読み込む機能は、GitHub PagesなどHTTP(S)で配信してください。アプリごとの操作方法や、寸法・教材内容の説明は画面内にあります。
