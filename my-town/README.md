# My Town — わたしの町を案内しよう

5年生の外国語で、自分の町をつくり、友達と道案内をする静的Webアプリです。

入口：`my-town/index.html`（互換入口：`my_town.html`）。サーバー側の処理、APIキー、外部CDNは使いません。

## 授業での使い方

1. 「町をつくる」で場所の絵を選び、地図の区画を押します。地図のマス数は4×4・5×5・6×6・8×8から選べ、同じ場所を複数置けます。初めは「よく使う場所」を表示します。「すべての場所」で元HTMLの40種類すべてを選べます。表示名は米国での使用を確認して調整しています。検索は英語名と表示している日本語訳に対応します。
2. 「道案内をする」で、「S 出発地を選ぶ」「G 目的地を選ぶ」を押してから地図の建物を押します。選択欄からも選べます（町全体の語彙street / townは地点指定の対象外です）。A1〜H8（マス数による）の位置記号で地図と選択欄を対応させます。
3. まず友達に英語で案内してから、「1つずつ見る」または「お手本を再生」で確認します。別の正しい道順もあり、お手本だけが正解という判定はしません。
4. 役割を交代します。「同じ道案内をもう一度」で条件を保ったまま出発地へ戻れます。

各場所の入口は絵のすぐ上の道に固定しています。キャラクターの矢印が現在の向きで、left / right はキャラクターから見た左右です。縦・横とも交差点から次の交差点までの距離を1 blockとし、Go straight for two blocks. のように正確な数を示します。途中の入口まで・入口からの距離も省かず、半ブロックは half a block、1.5ブロックは one and a half blocks とします。1 blockは単数形。地図にも、その直進区間で進む距離の1・2…や½の目印を表示し、通過すると色が変わります。

「マスの数」で区画を増やしても、今の建物の行・列を保ちます。縮小で外側の場所が消える場合は確認し、「1つ戻す」でマス数と配置・地点指定をまとめて戻せます。以前の4×4の保存ファイルも開けます。

「道案内を大きく見る」で、道案内専用の拡大画面を開けます。100・125・150・200%から倍率を選べ、案内・停止・再実演のボタンと現在の英文を画面内に表示します。地図はドラッグ不要で上下左右にスクロールでき、移動中はキャラクターを追って表示範囲を調整します。Escまたは「閉じる」で元の画面に戻ります。

地図用の絵は元の高解像度生成画像から白い余白を詰め、区画の中で大きく表示します。マスが小さくなりすぎる場合は地図領域の中だけスクロールします。タップとキーボードで配置でき、ドラッグは不要です。

## 保存・音声

- 町の名前・配置・出発地・目的地はこのブラウザーのlocalStorageに自動保存します。共有端末では他の人にも見えるため、ファイル保存と読み込みを使って町を持ち運べます。
- クリア・見本への変更・読み込み前に確認があり、「1つ戻す」で直前の町に戻せます。変更が続くと戻せるのは直前の1操作のみです。
- 英語の音声は初期OFF。ONにすると単語選択時とお手本確認時に読み上げます。声や発音は端末の英語音声に依存します。音声に失敗・無応答でも文字と動きで継続できます。
- 声の一覧をページ読込時に取得し、voiceschangedでも更新します。端末内の米国英語、端末内の別の英語、通信を使う米国英語、ほかの英語の順に選びます。無音発声のウォーミングアップには依存しません。開始に時間がかかる場合は準備中と表示し、4秒間開始しなければ音声を取り消して継続します。開始後は文の長さに応じた別の上限を使います。端末の合成エンジン自体の初回遅延は残る可能性があります。
- 「止めて出発地へ」、活動切替、画面を離れる操作で、古い再生を取り消します。
- ブラウザーの「動きを減らす」と、アプリの「動きを省く」に対応します。

## 曲がる向きの補助

- 8方向の立ち姿を追加生成し、隣り合う向きの絵を徐々に重ね替えることで、体を立てたまま滑らかに方向転換します。
- 頭上と足元の方向矢印も同じ角度で回転し、曲がる場所にはオレンジの曲線矢印を表示します。左右は、この子から見た左右です。
- 到着時の on your left / right では曲がる矢印を消します。
- 再生中の停止、地図の拡大・縮小、マス数変更で、古い処理が新しい画面を書き換えないことを確認しています。

## 画像

- `assets/places/*.webp`：40語分、各320×320。built-in `image_gen.imagegen` で個別に生成し、配信向けに形式変換しました。
- `assets/character/walk-sheet.png`：4方向×4コマの透明背景シート。512×640、1フレーム128×160。
- `assets/character/{south,west,east,north}-{0,1,2,3}.webp`：同じ16フレームの個別ファイル。
- `assets/map-places/*.webp`：地図用の40画像。縦横比を保持し、余白を詰めて最大512pxに変換。
- `assets/character/turn-sheet.webp` と `turn-0.webp`〜`turn-7.webp`：北・北東・東・南東・南・南西・西・北西の8方向。1フレーム128×160。元シートは `turn-source.png`。
- 追加画像のプロンプトと加工条件は `assets/turn-generation.json`。再加工は `scripts/prepare-my-town-view-assets.py`。
- 最終プロンプト全文と元生成ファイルの対応は `assets/generation.json` にあります。元の高解像度生成画像はimagegenの生成先に保持し、アプリには軽量な配信用画像を同梱します。

方向は上から南・西・東・北。列は静止・左足前・通過姿勢・右足前です。機械的に透明部分の境界を検出して切り出し、共通スケールと足元の位置をそろえています。加工を再現する場合は元生成シートを `walk-sheet.png` にコピーし、生成済みの個別フレームを別の場所に退避してから `python scripts/prepare-my-town-assets.py` を実行します。

## 検証・出典

`node scripts/qa-my-town.cjs` で原本の反例、全240経路、保存、停止、音声失敗、画像の復号、画面条件を検証します。追加の `node scripts/qa-my-town-map.cjs` は4サイズの全6,132経路、8方向転換、拡大・倍率変更、ファイル互換、確認画面の連続操作、再生中のマス数変更、追加49画像を検証します。WindowsのEdgeと、既存リポジトリと同じPlaywright環境を使います。画像の再配信用変換は `scripts/prepare-my-town-assets.py` です。

指摘と確認範囲は `REVIEW.md`、米国英語としての判断と出典は `ENGLISH-REVIEW.md`、原本は `source/original.html` に保持しています。

英語表現は米国国務省の教材、米国の大学・自治体・施設の実際の案内を再確認しました。現在は Start at the library. / Go straight. / Turn left. / Turn right. / The library is on your right. の形を使います。場所名はcommunity center / concert hall / burger restaurant / train stationに調整しました。詳細は `ENGLISH-REVIEW.md` を参照してください。

初版の授業表現は、文部科学省「小学校学習指導要領解説 外国語活動・外国語編」の道案内の例（Go straight. / Turn left. / Turn right. / You can see it on your right.）を参照しました。

- https://www.mext.go.jp/content/20220614-mxt_kyoiku02-100002607_11.pdf
- https://www.mext.go.jp/component/b_menu/shingi/toushin/__icsFiles/afieldfile/2018/09/26/1395320_0507.pdf

ポートフォリオの教材番号98に、実際の操作から録画した9.5秒の字幕付き動画を掲載。採用区間は `scripts/portfolio-demos-98.json` に保存しています。

実際の児童の理解・学習効果、学校端末の実機タッチ操作、スピーカーから聞こえる音声、スクリーンリーダーでの通し操作は未検証です。

距離の縦横・半ブロックは `node scripts/qa-my-town-map.cjs` の全6,132経路で検証。音声選択、一覧の遅延更新、開始待ち、停止後の古いコールバック、無応答時の継続は `node scripts/qa-my-town-speech.cjs` の模擬音声で検証します。模擬音声の検証は、実機から音が出るまでの短縮を保証しません。

## 2026-10-27 操作・表示の改善

狭い画面では絵の一覧を先に表示し、一覧と地図を往復するボタンを追加しました。選んだ絵を地図のそばで確認できます。地図直下にも現在の案内・訳・進み具合・次へ・停止を表示。拡大画面でもS/Gボタンから地点を指定できます。指摘と検証範囲は `USABILITY-REVIEW.md`、追加の操作検証は `node scripts/qa-my-town-usability.cjs` を参照してください。
