# My Town — わたしの町を案内しよう

5年生の外国語で、自分の町をつくり、友達と道案内をする静的Webアプリです。

入口：`my-town/index.html`（互換入口：`my_town.html`）。サーバー側の処理、APIキー、外部CDNは使いません。

## 授業での使い方

1. 「町をつくる」で場所の絵を選び、地図の区画を押します。16区画あり、同じ場所を複数置けます。初めは「よく使う場所」を表示します。「すべての場所」で元HTMLの40種類すべてを選べます。表示名は米国での使用を確認して調整しています。検索は英語名と表示している日本語訳に対応します。
2. 「道案内をする」で、S 出発地と G 目的地を選びます（町全体の語彙street / townは地点指定の対象外です）。A1〜D4の位置記号で地図と選択欄を対応させます。
3. まず友達に英語で案内してから、「1つずつ見る」または「お手本を再生」で確認します。別の正しい道順もあり、お手本だけが正解という判定はしません。
4. 役割を交代します。「同じ道案内をもう一度」で条件を保ったまま出発地へ戻れます。

各場所の入口は絵のすぐ上の道に固定しています。キャラクターの矢印が現在の向きで、left / right はキャラクターから見た左右です。直進区間の長さは動きで示し、半端な区間をブロック数として読ませません。

原本の5×5区画を4×4に整理し、絵と英語名を大きくしました。440px以下では、英語名を読めるサイズに保つため、地図の中だけ横スクロールできます。移動中にキャラクターが見えるようスクロール位置を調整します。タップとキーボードで配置でき、ドラッグは不要です。

## 保存・音声

- 町の名前・配置・出発地・目的地はこのブラウザーのlocalStorageに自動保存します。共有端末では他の人にも見えるため、ファイル保存と読み込みを使って町を持ち運べます。
- クリア・見本への変更・読み込み前に確認があり、「1つ戻す」で直前の町に戻せます。変更が続くと戻せるのは直前の1操作のみです。
- 英語の音声は初期OFF。ONにすると単語選択時とお手本確認時に読み上げます。声や発音は端末の英語音声に依存します。音声に失敗・無応答でも文字と動きで継続できます。
- 「止めて出発地へ」、活動切替、画面を離れる操作で、古い再生を取り消します。
- ブラウザーの「動きを減らす」と、アプリの「動きを省く」に対応します。

## 画像

- `assets/places/*.webp`：40語分、各320×320。built-in `image_gen.imagegen` で個別に生成し、配信向けに形式変換しました。
- `assets/character/walk-sheet.png`：4方向×4コマの透明背景シート。512×640、1フレーム128×160。
- `assets/character/{south,west,east,north}-{0,1,2,3}.webp`：同じ16フレームの個別ファイル。
- 最終プロンプト全文と元生成ファイルの対応は `assets/generation.json` にあります。元の高解像度生成画像はimagegenの生成先に保持し、アプリには軽量な配信用画像を同梱します。

方向は上から南・西・東・北。列は静止・左足前・通過姿勢・右足前です。機械的に透明部分の境界を検出して切り出し、共通スケールと足元の位置をそろえています。加工を再現する場合は元生成シートを `walk-sheet.png` にコピーし、生成済みの個別フレームを別の場所に退避してから `python scripts/prepare-my-town-assets.py` を実行します。

## 検証・出典

`node scripts/qa-my-town.cjs` で原本の反例、全240経路、保存、停止、音声失敗、画像の復号、画面条件を検証します。WindowsのEdgeと、既存リポジトリと同じPlaywright環境を使います。画像の再配信用変換は `scripts/prepare-my-town-assets.py` です。

指摘と確認範囲は `REVIEW.md`、米国英語としての判断と出典は `ENGLISH-REVIEW.md`、原本は `source/original.html` に保持しています。

英語表現は米国国務省の教材、米国の大学・自治体・施設の実際の案内を再確認しました。現在は Start at the library. / Go straight. / Turn left. / Turn right. / The library is on your right. の形を使います。場所名はcommunity center / concert hall / burger restaurant / train stationに調整しました。詳細は `ENGLISH-REVIEW.md` を参照してください。

初版の授業表現は、文部科学省「小学校学習指導要領解説 外国語活動・外国語編」の道案内の例（Go straight. / Turn left. / Turn right. / You can see it on your right.）を参照しました。
