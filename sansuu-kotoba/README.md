# する・される — 算数のことば

入口は `../sansuu_kotoba.html`。外部ライブラリ・通信・音声・保存データは不要です。HTMLを直接開くか、リポジトリのルートで `python -m http.server 8954 --bind 127.0.0.1` を起動し、`http://127.0.0.1:8954/sansuu_kotoba.html` を開きます。

## 教材の対応

左が「前／される側」、右が「うしろ／する側」。人物、式の数字、用語の横位置を揃えています。円弧は右を始点、左を終点とし、矢印の先は必ず「される側」に向きます。人物図と式の両方に表示します。

| 場面 | 左 | 右 | 式 |
| --- | --- | --- | --- |
| 押す | 押される人 | 押す人 | なし |
| 引く | 引かれる人／数 | 引く人／数 | 7 − 2 |
| 水をかける | かけられる人／数 | かける人／数 | 4 × 3 |
| 頭についた風船をわる | わられる人／数 | わる人／数 | 8 ÷ 2 |
| カレーにルーをたす | たされる人／数 | たす人／数 | 4 ＋ 3 |

動作は用語を記憶するための比喩であり、計算の数量モデルではありません。人の左右を固定し、人→数の切替時も矢印の方向を保ちます。確認問題は左右両方を交互に問います。不正解でも再回答でき、ヒントで人物ラベルを戻せます。自動再生は初期状態で停止、場面／学び方切替とページ非表示で停止します。低フレームレートの４コマ再生と手動コマ送りに対応します。

## 画像

組み込みの `image_gen` で同じ２人による４列×５行のシートを生成し、カレーが本人の皿に注がれるよう追修正しました。最終生成画像を `assets/source-sheet.png`、生成・修正プロンプト全文を `assets/generation-prompts.txt` に保存しています。外部の画像URLは使いません。

`python scripts/slice-sansuu-kotoba.py`（リポジトリのルートから実行、Pillowが必要）で罫線を検出して20枚に機械的に切り出します。絵の描き直しや補間は行いません。表示用は `assets/scene-行-コマ.webp`、行番号・コマ番号は0始まりです。画像生成の左右のわずかな位置揺れは残ります。

## 検証

横長画面（幅900px以上・高さ600px以上）では、絵と式の列に操作・確認問題の列を並べます。図の幅を利用可能な高さに合わせ、人物と数字の横位置と円弧の向きを保ちます。スマホや縦長画面では縦配置に戻ります。「おとなの方へ」は横長画面では開いたときだけ説明パネルとして表示します。

`node scripts/qa-sansuu-landscape.cjs` は1366×768、1366×640、1366×600、1280×600、1024×600、1180×620の6サイズで全場面・全モードとヒント・再回答を操作し、205状態でスクロール不要、表示とボタンの重なりなし、ラベルの収まりを検証します。端末実機ではなくEdgeによる画面サイズの再現です。公開URLを引数に指定して同じ確認を実行できます。

`node scripts/qa-sansuu-kotoba.cjs`。既存QAと同じバンドル版PlaywrightとローカルEdgeを使用します。全20コマの読込、全10種の用語確認、人物・数字の横位置一致、矢印の始終点、再生と場面切替の競合、375/390/768/1280px幅、動きを減らす設定、キーボード操作を検証します。画面キャプチャは `.portfolio-work/sansuu-kotoba/` に保存します。実際の児童の記憶定着効果は未測定です。
