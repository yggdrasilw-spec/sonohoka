# する・される — 算数のことば

入口は `../sansuu_kotoba.html`。外部ライブラリ・保存データは不要です。効果音はWeb Audioで合成し、読み上げは端末の日本語音声を使います（端末・選択される音声によって通信や音声の利用可否が異なります）。HTMLを直接開くか、リポジトリのルートで `python -m http.server 8954 --bind 127.0.0.1` を起動し、`http://127.0.0.1:8954/sansuu_kotoba.html` を開きます。

## 教材の対応

左が「前／される側」、右が「うしろ／する側」。人物、式の数字、用語の横位置を揃えています。円弧は右を始点、左を終点とし、矢印の先は必ず「される側」に向きます。「数につなげる」では同じ矢印を残し、人物と同じ場所に数字を重ねます。

| 場面 | 左 | 右 | 式 |
| --- | --- | --- | --- |
| 押す | 押される人 | 押す人 | なし |
| 引く | 引かれる人／数 | 引く人／数 | 7 − 2 |
| 水をかける | かけられる人／数 | かける人／数 | 4 × 3 |
| 頭についた風船をわる | わられる人／数 | わる人／数 | 8 ÷ 2 |
| カレーにルーをたす | たされる人／数 | たす人／数 | 4 ＋ 3 |

動作は用語を記憶するための比喩であり、計算の数量モデルではありません。人の左右を固定し、人→数の切替時も矢印の方向を保ちます。確認問題は左右両方を交互に問います。不正解でも再回答でき、ヒントで人物ラベルを戻せます。初期状態は停止。「② 数につなげる」を押すと、人物の４コマ→同じ位置に数字を重ねる→人物と用語が数へ変わる→演算記号の順に約5.6秒（ゆっくり設定は約10.4秒）で一度だけ再生します。最後は静止し、「もう一度」で見直せます。停止・再開・８段階のステップ送り・はじめへ戻る操作に対応。場面切替とページ非表示で停止します。動きを減らす設定では変化を再生せず、完成した式を表示します。低フレームレートの４コマ再生と手動コマ送りに対応します。

## ④ 文の意味：応用問題

基本の３モードに続き、「④ 文の意味」で用語を使う文を読み、対応する式や増減を３択で選びます。四則各３パターン×数値３セットの36問です。演算別の９問、または全36問を混ぜて、１巡内では重複しない順に出します。最初は図を隠し、「図のヒント」・不正解・正解で、前後の数量図と説明を表示します。

- かけ算：かけられる数とかける数の交換／かける数を１増やす／かけられる数を１増やす。
- ひき算：答え＋引く数＝引かれる数の確認／引かれる数を１増やす／引く数を１増やす。
- たし算：たされる数とたす数の交換／たす数を１増やす／答えからたす数を引いて戻す。
- わり算：あまりのない計算の答え×わる数＝わられる数の確認／わられる数をわる数の分増やす／わる数を２倍にする。

数量図はSVGで構成し、乗法は「左の数こずつ・右の数組」、除法は「わる数こずつの組がいくつ」、加減は合成・分離した１こ単位のブロックを描きます。ヒント利用や誤答後の正解は「ヒントなしで最初に正解」に加算しません。得点は画面を開いている間だけ保持します。

`node scripts/qa-sansuu-practice.cjs` で全36問の独立計算による正答・図の数量一致、誤答・ヒントの得点、同じ問題の重複加点防止、演算別９問と混合36問の重複防止、横長６サイズとスマホを確認します。図解の実寸とカード内の収まりも検証します。

## 音と演出

初期表示では音を出さず、ボタン操作後に効果音・声を使います。「効果音」「声」は別々に切替でき、「よむ」で現在の説明・問題・選択肢を再読します。「音をとめる」は音声・効果音と人物の再生を停止します。設定はこの画面を開いている間だけ保持します。

- 引く・水をかける・風船をわる・ルーをたす・押す場面それぞれの短い合成効果音。
- 人物→数字、用語の「人→数」、完成の各タイミングに案内と短いチャイム。数字の拡大・光の輪は同じ再生時間に同期します。
- 声が入のときは、その場面の読み上げ終了まで次の段階へ進みません。声が切のときは従来の約5.6秒で変化します。
- 数・演算記号・「引く」等に明示的な日本語の読みを渡します。実際の声質・抑揚は端末に依存します。
- 誤答には短い案内、正解には和音と控えめなボタンの拡大。問題文・選択肢・図のヒント・正解の解説も読み上げます。
- 場面・モード・問題の切替とページを隠したときは古い音声を取り消します。終了イベントが来ない音声は最大45秒で待機を解除します。読み上げ・Web Audioの非対応端末では対応するボタンを無効化し、文字と操作は使えます。
- 動きを減らす設定では光の輪と拡大を省きます。音は個別に切り替えられます。

`node scripts/qa-sansuu-audio.cjs` は制御した音声イベントで、読み上げ中の待機・段階順・日本語の読み・途中取消・ミュート・選択肢の再読・ページ非表示・終了通知なし・非対応環境を検証します。効果音は実際のWeb Audioノードの発音を検証します。自動検証は声の聞き取りや実機スピーカーの音量・音質の確認ではありません。

参照：[SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis)、[AudioContext](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext)。

## 左右の人物の確認と表記

「① 人で見る」の選択・最初からの再生・「よむ」で、場面の説明→左の役割→右の役割の順に読み上げます。「② 数につなげる」の導入と用語変化・完成時にも左右を分けます。説明している人物だけを、その役割の色の角丸枠とグロウで囲み、対応する用語も強調します。画像は既存の４コマを使用します。

子ども向けUI・問題文・ヒント・図・アクセシビリティ用ラベルは、[文部科学省の学年別漢字配当表](https://www.mext.go.jp/content/1413522_001.pdf)の第２学年までの漢字に限定しています。「押す」「矢印」「根元」「式」「意味」「問題」「効果音」などは「おす」「やじるし」「ねもと」「しき」「いみ」「もんだい」「おと」に変更しています。個々の学校での２年生の学習順序までは前提にしていません。おとな向けの説明は対象外です。

`node scripts/qa-sansuu-roles.cjs` で５場面の左右の人物と用語の一致、１人ずつの強調、停止と遅延通知、375/768/1180px幅、動きを減らす設定を確認します。全モードと全36問を巡回して、子ども向け表示とaria-labelに配当外の漢字がないことも点検します。

## ② ブロックで見る

「② 数につなげる」の「すうじ／ブロック」で切り替えます。ブロックはSVGで描き、人物の説明→同じ位置でブロックへ変わる→数量操作→１こずつの数え上げ→答えの順で再生します。「声」が入なら説明と各カウントの読み上げを待ちます。途中停止・ステップ送り・はじめへ・もういちど・動きを減らす設定に対応します。

- 7−2：７このうち２こだけにロープをかけて右へ引き出します。引いた２こも見せたまま、残り５こだけを数えます。
- 4＋3：４こと３こを合わせ、７こを数えます。
- 4×3：４この１つ分から、４こずつのまとまりを３つ分まで増やし、全部の12こを数えます。右の３は３個の追加ブロックではなく「３つ分」です。
- 8÷2：１つの手袋が８このうち４こをまとめて握り、１つ目の箱へ運んで開いて置き、残り４こでも同じ操作を繰り返します。１つ分の４こを数えます（等分除）。右の２は分ける場所の数です。④の既存の包含除の図は変更していません。

答えは数え上げが終わるまで「？」です。引く・足す・分ける途中もブロックの総数を保ち、かけ算は１組４こを保って組を増やします。人物の比喩と数量モデルを区別し、数字の右側の役割を各演算に合わせて説明します。表示・音声原稿は２年生までの配当漢字に合わせます。「1つ」「2つ」「3つ」には「ひとつ」「ふたつ」「みっつ」の読みを渡します。

`node scripts/qa-sansuu-blocks.cjs` は四則合計1,612時点を独立した期待値で調べ、総個数、除外したブロックを数えないこと、かけ算の４こ×３組、等分除の２組×４こ、答えの先出しがないこと、配当漢字を検証します。UIでは全ステップ、表示切替、途中停止、自動再生の最後の停止、動きを減らす設定、横長と縦長７サイズ、数え上げ中の音声待ちと音停止も確認します。

### 白い手袋の操作

手袋は画面に最大１つだけです。組み込みの `image_gen` で「開く・包む・握る・横から押す」の４姿勢を透過画像として作りました。原本は `assets/gloves/*-source.png`、表示用は `open.webp` / `cup.webp` / `grip.webp` / `push.webp`、生成プロンプト全文は `assets/gloves/prompts.json` に保存しています。`node scripts/prepare-sansuu-gloves.cjs` はアルファを検証して384×384のWebPへ圧縮するだけで、絵や背景の描画編集はしません。

- ひく：手袋が引く２こをロープでまとめ、結んだロープを握って、２こと一緒に右へ引き出します。
- たす：もとの４こは動かさず、手袋が追加の３こを横から押して合流させます。
- かける：１つ分の４こを手のひらに集めて握り、開くと同じ４こずつが３セット飛び出します。握っている間は「手の中に４こ」と示します。
- わる：４こを握る→１つ目の箱へ運ぶ→開いて置く→空の手で残りへ戻る→同じ４こを握る→２つ目へ運んで置く、の繰り返しです。手袋を増やさず、元の８こがなくなるまで繰り返します。元の残り・手の中・置いた数の合計は常に８です。

手で隠れたブロックも同じIDで保持し、表示用の別ブロックを重複して作りません。手の姿勢と個数・位置は同一の時刻から計算します。停止・コマ送り・場面切替で手とブロックが別々に進むことはありません。動きを減らす設定では完成図へ進みます。

ブロックQAでは1,612時点で数量・数え上げ・手袋が最大１つであることを確認します。わり算の運搬２回は「元４・手４・箱０」→「元４・手０・箱４」→「元０・手４・箱４」→「元０・手０・箱８」となり、最初の４このIDと次の４このIDも追跡します。かけ算では握っている間に４こが手の中にあり、開いた後は４こずつ３組になること、たし算ではもとの４この位置が変わらないこと、ひき算ではロープと握る手が離れないことも検証します。音声イベントの同期は模擬イベントによる検証を含み、実際の児童の認知負荷の変化は未測定です。

### 握りの中間コマ・接触点・立体ブロック（v2）

開く→握るの８段階を `assets/gloves/close-sheet-v2.png` から切り出し、手首の位置をそろえて `close-0.webp`〜`close-7.webp` にしました。逆順で開きます。`prepare-sansuu-glove-animation.cjs` は透明な行間を検出して切り出し、カフの下端を同じ座標へ平行移動して余白を付けます。手の絵そのものの変形・補間生成はしません。

ロープの握りは、ユーザー提供の赤い手袋の写真を参照して白手袋へ描き直した `rope-grip-photo-v2.png` / `rope-grip-v2.webp` を採用しています。参考写真そのものは公開アセットに含めません。生成記録は `prompts-v2.json`、切り出しと基準点は `animation-v2.json`。それ以前に試した不自然なロープ握りの生成画像は採用していません。

画像上の握り点・ロープ入口・出口を固定し、画像と端点へ同じ左右反転・回転・拡大縮小・平行移動の行列を適用します。SVGのロープは変換後の入口へ接続します。引き始める前にたるみを取り、引く間はブロック・巻いたロープ・手に同じ移動量を与えます。たし算では画像の手のひら側の接触点を追加ブロックの右端へ合わせ、接触するまでブロックを動かしません。

握る・開くでは８枚を共通の掌基準点で切り替え、半分ほど閉じたところで手前／奥の描画順を切り替えます。再生はrequestAnimationFrameへ合わせ、SVGと手のimageノードを毎回破棄せず属性を更新します。手首やロープの点を別々に動かすCSSアニメーションは使いません。停止した時刻ではすべて同じ状態に止まります。

数図ブロックは50×50の上面に約6pxの厚み、丸い縁、控えめなハイライトと接地影を追加しました。左右への斜めの張り出しは加えず、整列と個数管理の座標を保っています。

ブロックQAは1,612時点の数量に加え、変換後の画像端点とSVGロープの一致（ブラウザ行列の丸めを含め0.001px以内）、ロープ両端の角度、引く手とブロックの移動量、押す手の接触点、８段階の使用、同じimageノードを再利用していることも確認します。画像の見え方は画面キャプチャでも点検します。児童の認知負荷が下がったという実測結果ではありません。
