# 教科書のスクリーンショットから「読み返しクイズ」を作るプロンプト

添付された完成アプリとレビュー結果から再構成した、授業準備用のテンプレートです。教科書の画像や本文は生成時の添付として扱い、このファイルには含めていません。

~~~text
添付した国語教科書のスクリーンショットをもとに、物語を一度読んだ児童が、クイズをきっかけに本文を読み返す、非公開のWebアプリを作ってください。

作品名、対象学年、問題数は私の指定を優先してください。問題数の目安は20問です。本文で答えを確かめられる問題が足りなければ、無理に水増ししないでください。

【出題】
- 物語の流れに沿って、何が起きたか、誰が何を言ったか・したか、その前後で何が変わったかを尋ねる三択を作ってください。細かな数字や固有名の暗記に偏らせないでください。
- 表現を問うときは、比喩が表す様子と実際の出来事を区別してください。語り手の説明と登場人物の考えも区別して設問を書いてください。
- 各問について、選択肢をすべて本文と照合してください。別の選択肢も本文の範囲で成立するなら、設問と選択肢を調整してください。見解が分かれる解釈を唯一の正解にする必要はありません。
- 選択肢の位置は偏らせず、挿絵や画面の見出しだけで正解が決まらないようにしてください。

【読み返しと振り返り】
- 各問に、答えを確かめるページと右から数えた行番号の範囲を指定してください。根拠が複数行や見開きの両ページにまたがる場合は、必要な箇所すべてに目印を付けてください。
- 回答前に自分でヒントを開閉できるようにしてください。答えの語句をヒントの見出しで先に表示せず、読む場所を案内してください。
- 回答したら、正誤を文字で示し、どの言葉や行動が答えの根拠かを短く説明してください。誤答の際は、児童が本文に戻って確かめられるようにしてください。
- 未回答では先へ進まず、連打で得点や問題番号が二重に進まないようにしてください。結果には読み返す場所を残し、まちがえた問題だけでもう一度挑戦できるようにしてください。

【納品前の確認】
- 全問について、正答・誤答・根拠行・解説・ページ表示を照合してください。判読できない箇所を出題の根拠にせず、確認事項に残してください。
- 320px程度の小型画面とタブレットの縦横で、開始、ヒント開閉、解答、結果、誤答の再挑戦を確認してください。キーボードでも選べるようにしてください。
- ローカルで開くHTMLと、必要な場合は同じフォルダーに置くCSS・JavaScriptを納品してください。外部サービスへの送信、外部CDN、公開デプロイは不要です。確認事項と実行したテストを短く添えてください。
~~~
