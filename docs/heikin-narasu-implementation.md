# ならして ぴったり！ 実装・確認

2026-10-24。入口：`heikin_narasu.html`。外部ライブラリー・画像・通信サービス不要。

## 教材の流れ

1. 玉：最上段の1個を移す。ドラッグ、元→先のタップ、Tab＋Enter／Spaceに対応。玉ごとの白・黒の色を保持し、移動中・移動後も積み位置によって色を変えない。取り消し・保存再開でも色を保持し、色の記録がない旧保存には復元時に初期色を割り当てる。`node scripts/qa-heikin-bead-colors.cjs` で確認。
2. 土：**見る教材**。同じ大きさの小さな土の塊を、ブルドーザーが横へ押し、下が空いた塊が落ちて低いところにたまる。右へ押せなくなったら、バック・奥への迂回・方向転換を経て左向きにならす。再生前に押し始める高さ（下から1段目〜山の最高段）と、「選んだ高さだけ／一層ずつ下げる」を選ぶ。5種類の地面、停止・再開、再視聴。移動先選択や正解入力は設けない。
3. 水：2〜5個の同じ300mLコップを10／50mLずつ移す。コップ本体を持ち上げて運び、傾けて注いでから元の場所へ戻す。教師の数値が5mL単位の場合は5mLの操作も使える。初期問題の平均は2〜5個の順に120・100・150・160mLと変え、どの個数でも同じ答えになる配置を避ける。
4. 水差し：直前の水の初期値・現在量を引き継ぎ、回収後、水差しにコップの個数に対応する等分の横線を表示して、元の個数へ等分。1巡だけ配る／最後まで分ける。ここで「平均」を紹介。
5. 式：合計→個数→1個分を順に入力。元の量を残したまま図を縮小／非表示／再表示。
6. 練習：玉、水、合計と個数、図を隠した式、文章題、0mLのコップ、平均125mLの7問。
7. つかう：ジュース・卵・魚・得点・全体量の予想・タイヤの測定・失敗した実験・歩幅の8問。既存の練習の次から進むほか、タブと問題選択で直接選べる。

土の場面の操作ボタンの下に、折りたたみ式の「参考動画：実際のグラウンド整備を見る」を置く。ユーザー指定の「トンボのかけ方（阪神園芸）」 https://youtu.be/fY-4ZaPRe3E と「グラウンド整備（浦和学院）」 https://youtu.be/P5qvrHpeMwE をYouTubeの別タブで開く。埋め込みや自動再生は行わない。

練習と式の場面では、合計の確認欄を自動で開かない。教師設定のヒント線も練習開始時には表示せず、ヒントを3段階進めるか実際にならしたときに表示する。文章ヒントは考え方→量の確認→計算の手がかりの順に出し、玉の問題には移し方のヒントを出す。入力途中の答えはヒントを開いても残す。

「図が動くヒント」は図を表示し、多い棒・コップから少ないところへ順に移して、同じ量までならす。図を隠した問題や式の場面も同じ動きで確かめられる。入力への正解判定や合計→個数→平均の回答段階は自動で進めない。一時停止・再開、やり直し、場面切替で停止できる。もう一度押すと元の量から再生する。`node scripts/qa-heikin-hints.cjs` で7問・総量保存・停止／取消・初期表示を確認する。

元の設計書 `heikin-narasu-design.md` の土の場面は、本チャットのユーザー指示に従って操作課題から、条件を選んで再生する動画教材（数値に連動するSVG）に変更した。動画ファイルのロードや再生環境を必要とせず、数値を変えて同じ動きを再生できる。

## 状態と保存

元の量、現在量、バケット、水差し、場面、入力の段階を一つの状態で管理。移動時は元・先・移動中の量を同じ状態から表示し、常に総量を保存する。移動前の状態からアニメーションを描き、完了時だけ確定・保存。停止／取消／場面変更では古いフレームを無効化する。等分は1巡または全配分が1回の履歴になる。

localStorageに個人情報を含めず保存し、再訪時に「つづきから／さいしょから」を選べる。移動中に閉じても直前の確定状態に戻る。土の場面は、再訪時には元の地面と選んだ高さ・押し方に戻り、再生ボタンを待つ。左側にくぼみがある教師入力も受け付け、必要に応じて反対側からならす。

設定は問題の数値、ヒント線、玉の数量、読み上げ、速度。水量の数値は常時表示。容量や同じ量にできる刻みを検証し、成立しない問題は設定画面で止める。読み上げは「聞く」を押したときだけ行う。

## 土と水の動き（2026-10-24改良）

土は高さ1単位あたり8個の塊として描き、各塊のIDを保持する。バケット前に連なった土を同じ高さのまま横に1列押してから、支えがなくなった塊を真下に落とす。横移動と落下の段階を分け、放物線で山へ飛ばさない。端に詰まった場合は土を動かさずに車体をバックさせ、奥の経路で右へ迂回、方向転換、手前への復帰後に左へ押す。5種類の地面のうち3番目はこの折り返しを見せる配置。量は全フレームで保存する。開始時に完成高さの線は出さない。選んだ切削高さだけを点線で示し、その高さ以上の土を押す。「一層ずつ下げる」は端で車体を反転する際に高さを1段下げ、実際に各列の高さがそろったところで止まる。選んだ高さが高ければ凹凸が残り、低すぎれば土の行き場がなくなって停止する。完成時に平均の図へ差し替える処理は行わず、実際の粒子配置を保持する。これは格子上の教材モデルであり、摩擦・崩落角まで扱う土質シミュレーションではない。

水は固定幅76・高さ180・容量300mLのコップを共通に使う。`heikin-narasu-motion.js` が容器の内側の長方形を回転し、世界座標で水平な線より下の多角形を切り出す。その面積が残量に一致する水面位置を二分探索する。注ぎ出す角度も、下側の縁に水面が達する角度から計算。水面だけを容器と一緒に傾ける描画にはしない。

注ぐ動きは持ち上げ・移動・傾斜・注水・起こす・元へ戻すの順。注水中は容器の縁を受け側の上に保ち、水流の落下は重力を含む軌道で計算する。受け側の水面が上がれば水流の終点も上がる。コップからコップ／水差し、水差しから各コップに共通の処理を使う。原則2.4秒で1回の注水を見せる。「動きを少なく」では短い遷移にする。

追加確認：`node scripts/qa-heikin-soil.cjs`（806配置・44,595イベントの横移動、真下への落下、支持、重なりなし、量の保存、迂回と逆向き走行）、`node scripts/qa-heikin-geometry.cjs`（水面・面積・注ぐ角度）、`node scripts/qa-heikin-motion.cjs`（実ブラウザーで途中の動き、停止・再開、迂回・逆走、水差しの等分線と注水）。追加の `node scripts/qa-heikin-soil-controls.cjs` は開始前の線非表示・高さ選択・一層ずつ降下・低い高さでの停止・再訪・水の異なる平均を確認する。画像とブラウザー検証結果は `.portfolio-work/heikin-motion/` と `.portfolio-work/heikin-soil-controls/` に保存する。

水差しの等分線は回収完了後に表示し、コップn個に対してn−1本。水差しの断面積が一定なので、高さをn等分すると水量もn等分になる。線は初めに集めた全量を基準に固定し、分配途中も動かさず、傾ける際は容器と一緒に回転する。

## 画像付きの利用問題（2026-10-25）

`heikin-narasu-applications.js` の `problems` に、問題文・数値・単位・題材の図・ヒントの分岐・解説をまとめた。図はオリジナルのインラインSVGで、外部サービスや画像のダウンロードは不要。先生の自由な問題・画像登録機能は今回の追加には含めない。

- 平均：ジュース80mL、卵55g、魚28.5cm、6試合の得点2.5点。
- 全体の予想：1個分の平均80mLを求めてから、20個分の1600mLを予想する。実際の合計と必ず一致するとは説明しない。
- 測定：タイヤ1回転分の5回の測定から150.5cmを求める。
- 失敗した実験：手が当たって止めた2回目0.8mは、成功したときの道のりを調べる目的に合わせて除く。残る4回の平均7.7mと全5回の平均6.32mを解説で比べ、「小さい値だから除く」とは教えない。0点の試合は6試合のうちの1試合として残す。
- 歩幅：10歩分を3回測った平均647cmから、1歩分64.7cmを求め、整数に四捨五入して約65cmとする。

「ならす動きを見る」は、実物の形を変える操作ではなく、量を表す棒の多い部分を少ない部分へ移す図のヒント。全フレームで計算に使う合計を保存する。表示する途中の数値は0.1刻みで移し、細かすぎる小数を避ける。失敗した回は図でも印を付けて除き、元の測定値は画像カードに残す。ヒントは正解・回答段階を自動で進めない。狭い画面では図だけ横スクロールする。

検証：`node scripts/qa-heikin-applications.cjs`。8問の正誤、2段階の予想・四捨五入、0と失敗の区別、途中の量の保存、停止・取り消し・リセット・問題/場面切替・保存再開、不正な保存データの拒否、4幅×8問の横はみ出しを確認する。画像は `.portfolio-work/heikin-applications/` に保存する。既存の動くヒントは `node scripts/qa-heikin-hints.cjs` で別途検証する。
