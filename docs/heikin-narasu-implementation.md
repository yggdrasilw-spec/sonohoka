# ならして ぴったり！ 実装・確認

2026-10-24。入口：`heikin_narasu.html`。外部ライブラリー・画像・通信サービス不要。

## 教材の流れ

1. 玉：最上段の1個を移す。ドラッグ、元→先のタップ、Tab＋Enter／Spaceに対応。
2. 土：**見る教材**。同じ大きさの小さな塊を、ブルドーザーが土の塊を横へ押し、下が空いた塊が落ちて低いところにたまる。右へ押せなくなったら、バック・奥への迂回・方向転換を経て左向きにならす。5種類の地面、停止・再開、再視聴。児童への問題・移動先選択は設けない。
3. 水：2〜5個の同じ300mLコップを10／50mLずつ移す。コップ本体を持ち上げて運び、傾けて注いでから元の場所へ戻す。教師の数値が5mL単位の場合は5mLの操作も使える。
4. 水差し：直前の水の初期値・現在量を引き継ぎ、回収後、水差しにコップの個数に対応する等分の横線を表示して、元の個数へ等分。1巡だけ配る／最後まで分ける。ここで「平均」を紹介。
5. 式：合計→個数→1個分を順に入力。元の量を残したまま図を縮小／非表示／再表示。
6. 練習：玉、水、合計と個数、図を隠した式、文章題、0mLのコップ、平均125mLの7問。

元の設計書 `heikin-narasu-design.md` の土の場面は、本チャットのユーザー指示に従って操作課題から自動再生の動画教材（数値に連動するSVG）に変更した。動画ファイルのロードや再生環境を必要とせず、数値を変えて同じ動きを再生できる。

## 状態と保存

元の量、現在量、バケット、水差し、場面、入力の段階を一つの状態で管理。移動時は元・先・移動中の量を同じ状態から表示し、常に総量を保存する。移動前の状態からアニメーションを描き、完了時だけ確定・保存。停止／取消／場面変更では古いフレームを無効化する。等分は1巡または全配分が1回の履歴になる。

localStorageに個人情報を含めず保存し、再訪時に「つづきから／さいしょから」を選べる。移動中に閉じても直前の確定状態に戻る。土の場面は、再訪時には元の地面から再生する。左側にくぼみがある教師入力も受け付け、必要に応じて反対側からならす。

設定は問題の数値、ヒント線、玉の数量、読み上げ、速度。水量の数値は常時表示。容量や同じ量にできる刻みを検証し、成立しない問題は設定画面で止める。読み上げは「聞く」を押したときだけ行う。

## 土と水の動き（2026-10-24改良）

土は高さ1単位あたり8個の塊として描き、各塊のIDを保持する。バケット前に連なった土を同じ高さのまま横に1列押してから、支えがなくなった塊を真下に落とす。横移動と落下の段階を分け、放物線で山へ飛ばさない。端に詰まった場合は土を動かさずに車体をバックさせ、奥の経路で右へ迂回、方向転換、手前への復帰後に左へ押す。5種類の地面のうち3番目はこの折り返しを見せる配置。量は全フレームで保存する。これは格子上の教材モデルであり、摩擦・崩落角まで扱う土質シミュレーションではない。

水は固定幅76・高さ180・容量300mLのコップを共通に使う。`heikin-narasu-motion.js` が容器の内側の長方形を回転し、世界座標で水平な線より下の多角形を切り出す。その面積が残量に一致する水面位置を二分探索する。注ぎ出す角度も、下側の縁に水面が達する角度から計算。水面だけを容器と一緒に傾ける描画にはしない。

注ぐ動きは持ち上げ・移動・傾斜・注水・起こす・元へ戻すの順。注水中は容器の縁を受け側の上に保ち、水流の落下は重力を含む軌道で計算する。受け側の水面が上がれば水流の終点も上がる。コップからコップ／水差し、水差しから各コップに共通の処理を使う。原則2.4秒で1回の注水を見せる。「動きを少なく」では短い遷移にする。

追加確認：`node scripts/qa-heikin-soil.cjs`（716配置・39,596イベントの横移動、真下への落下、支持、重なりなし、量の保存、迂回と逆向き走行）、`node scripts/qa-heikin-geometry.cjs`（水面・面積・注ぐ角度）、`node scripts/qa-heikin-motion.cjs`（実ブラウザーで途中の動き、停止・再開、迂回・逆走、水差しの等分線と注水）。画像とブラウザー検証結果は `.portfolio-work/heikin-motion/` に保存する。

水差しの等分線は回収完了後に表示し、コップn個に対してn−1本。水差しの断面積が一定なので、高さをn等分すると水量もn等分になる。線は初めに集めた全量を基準に固定し、分配途中も動かさず、傾ける際は容器と一緒に回転する。
