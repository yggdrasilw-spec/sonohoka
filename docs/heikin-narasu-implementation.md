# ならして ぴったり！ 実装・確認

2026-10-24。入口：`heikin_narasu.html`。外部ライブラリー・画像・通信サービス不要。

## 教材の流れ

1. 玉：最上段の1個を移す。ドラッグ、元→先のタップ、Tab＋Enter／Spaceに対応。
2. 土：**見る教材**。場面を開くと重機が自動で高い土を削り、バケットで低いところへ運んで入れる。5種類の地面、停止・再開、再視聴。児童への問題・移動先選択は設けない。
3. 水：2〜5個の同じ300mLコップを10／50mLずつ移す。教師の数値が5mL単位の場合は5mLの操作も使える。
4. 水差し：直前の水の初期値・現在量を引き継ぎ、回収してから元の個数へ等分。1巡だけ配る／最後まで分ける。ここで「平均」を紹介。
5. 式：合計→個数→1個分を順に入力。元の量を残したまま図を縮小／非表示／再表示。
6. 練習：玉、水、合計と個数、図を隠した式、文章題、0mLのコップ、平均125mLの7問。

元の設計書 `heikin-narasu-design.md` の土の場面は、本チャットのユーザー指示に従って操作課題から自動再生の動画教材（数値に連動するSVG）に変更した。動画ファイルのロードや再生環境を必要とせず、数値を変えて同じ動きを再生できる。

## 状態と保存

元の量、現在量、バケット、水差し、場面、入力の段階を一つの状態で管理。移動時は元・先・移動中の量を同じ状態から表示し、常に総量を保存する。移動前の状態からアニメーションを描き、完了時だけ確定・保存。停止／取消／場面変更では古いフレームを無効化する。等分は1巡または全配分が1回の履歴になる。

localStorageに個人情報を含めず保存し、再訪時に「つづきから／さいしょから」を選べる。移動中に閉じても直前の確定状態に戻る。土の場面を再開した場合は、そこから自動でならす。

設定は問題の数値、ヒント線、玉の数量、読み上げ、速度。水量の数値は常時表示。容量や同じ量にできる刻みを検証し、成立しない問題は設定画面で止める。読み上げは「聞く」を押したときだけ行う。
