# 教科書のスクリーンショットから「ことばの解説アプリ」を作るプロンプト

添付された完成アプリとレビュー結果から再構成した、授業準備用のテンプレートです。教科書の画像や本文は生成時の添付として扱い、このファイルには含めていません。

~~~text
添付した国語教科書のスクリーンショットをもとに、児童が物語を読みながら難しいことばを確かめる、非公開のWebアプリを作ってください。

作品名と対象学年は、私の指定を優先してください。指定がなければ添付から読み取れる範囲で判断し、確かめられない情報は作らないでください。

【本文とページ】
- 添付のページ番号と掲載順を確認し、縦書きで右から左へ読める見開きにしてください。各ページの行順、会話の話者、読みがな、場面の区切りを維持してください。
- 画像が切れている箇所や、判読できない文字と読みがなは推測で埋めず、ページとおよその位置を確認事項に残してください。
- 前後の見開きに進むボタンとページ一覧を用意してください。スマートフォンでは縦書きを縮めすぎず、横に移動して読めるようにしてください。

【ことばの解説】
- 知らないと場面がわかりにくい語、昔の道具や言い回し、たとえを選び、本文からタップまたはキーボードで開けるようにしてください。行をまたぐ語はどちらの部分から開いても同じ解説を出してください。
- 解説には読み、学年に合う短い意味、この場面では何を指すか、他の場面でも使える自作の例文を載せてください。ことば一般の意味と物語の中での使い方は分けて書いてください。
- 道具や動作など絵で分かりやすくなる語には、本文の挿絵を写さず、自作の簡単な図を添えてください。絵や音声がなくても意味を確認できるようにしてください。
- ふりがなと語句の強調を切り替え、文字の大きさを変更できるようにしてください。読み上げを付けるなら端末内の日本語音声を使い、解説を閉じたら止めてください。
- 解説は閉じるボタンとEscキーで閉じ、開いた語句に操作を戻してください。

【納品前の確認】
- 見開きごとに、語句を押して読み・意味・場面・例文がその語に対応しているか確認してください。本文にある語句の読みや意味で判断に迷った場合は確認事項に残してください。
- 320px程度の小型画面とタブレットの縦横で、本文・文字サイズ変更・解説の開閉を確認してください。
- ローカルで開くHTMLと、必要な場合は同じフォルダーに置くCSS・JavaScriptを納品してください。外部サービスへの送信、外部CDN、公開デプロイは不要です。確認事項と実行したテストを短く添えてください。
~~~
