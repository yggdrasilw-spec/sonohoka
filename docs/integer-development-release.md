# 整数の性質・発展の追加

数のカードの順位教材 `card_rank_number.html` を公開用に追加。
既存教材に対応する図解解説の原版とレビュー証拠は別の非公開リポジトリへ移動し、このリポジトリには含めない。
ポートフォリオの教材84は公開リンク、教材85は概要と「非公開・保管済み」の表示だけとする。教材85にはリンク・元問題・画面・紹介動画を付けない。

## 発展教材

`seisuu-hatten.html` は整数の一般的な数学的性質を扱う。問題文を新たに作成し、初期値と題材を変更した。

- 数字カード：2・5・8。3枚すべてを1回ずつ使う条件を明示。
- おみやげ袋：グミ20個・ラムネ30個。最大10袋、各袋はグミ2個・ラムネ3個。
- 布パーツ：4cm×10cm。向きを変えない敷きつめで、最小の正方形は1辺20cm。
- 温室の水やり：9分ごと・12分ごと、開始午前9時。次の一致は午前9時36分。

公開用本文には「テスト」「大問」、元の駅名・菓子名は残さない。数値や名詞の変更だけで権利上の問題がなくなるとの保証はしない。元のテストの出典・許諾は未確認。

`seisuu_no_seishitsu_yasashiku.html` の開始画面・上部・時間と内容の選択・終了画面から、任意の発展画面を開ける。発展を閉じると元の学習に戻る。元の場面・回答・学習記録は変更せず、閉じる際に埋め込み画面を破棄し、アニメーションも終了する。

## 検証

`node scripts/qa-integer-release.cjs` を使用。独立した列挙による順位66,000条件、偶奇4,000条件、最大公約数3,600条件、最小公倍数と時刻900条件を検証する。PC・タブレット・携帯幅、発展の全場面、元の学習記録保持、Escape・フォーカス復帰、ポートフォリオの公開リンクと非公開表示を確認する。

スクリーンショットなどの一時証拠は `.integer-release-qa/` に保存。実機Safari・iOS・Androidと実際の学習効果は未検証。
