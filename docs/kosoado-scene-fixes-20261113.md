# こそあど言葉マスター：場面SVGの洗い出しと修正（2026-11-13）

ユーザー指摘（ケーキが地面にある／「どうやって」のハサミが複数／木かげの木が小さく話者が木かげに入っていない／部屋の中のはずが外、など）を受け、基本91問と応用17場面の場面描画を全点検した。描画はデータ駆動（基本は place と type から renderScene が合成、応用は advScene）のため、修正はデータ（place指定）と描画関数の両方に行った。

## 修正内容

|対象|問題|修正|
|---|---|---|
|基本 obj「これは、わたしが作ったケーキ」|ケーキが野外の地面|place を desk に変更（部屋の中で話し手の机の上）|
|基本 mod「このケーキ、おいしそう」|同上|place を desk に変更|
|基本 obj「これで、紙を切るよ」|ハサミが地面に置かれた絵|place を hand に変更（話し手が手に持つ）|
|基本 mod「このえんぴつを使ってね」|えんぴつが草の上|place を desk に変更|
|基本 obj「それを取ってくれる？」（けしゴム）|けしゴムが草の上|place を desk に変更（聞き手の机の上）|
|基本「どれ／どの／どんな／どういう」のケーキ・本・ハサミ・紙|候補3つが野外の地面に並ぶ|renderScene の根拠3（unknown）描画を変更：部屋の背景＋長いテーブルの上に候補を並べる。かばんは部屋の床に並べる|
|基本 way「はさみは、どうやって使うの？」|「どれ」型描画の流用でハサミが3つ並ぶ|way 系列の根拠3は候補ではなく単体1つだけ描く（紙の「どうやって折るの」も同様）|

|応用2「おべんとうは どこで？」|木が小さく、木かげが描かれておらず、さくらが木かげに入っていない|objs の小さい木を廃止し、shade 指定を追加。advScene が人物の背後に大きな木（幹＋枝＋3つの樹冠）を描き、地面に濃い日かげの楕円を敷いて、さくらがその中に入る。ゆうと側には太陽を描き、日なたとの対比を明示|
|応用12「公園への道」（目じるしの木）|遠くの木が小さく目じるしとして弱い|木の拡大率を 0.9→1.25 に|

## 点検して変更しなかったもの（判断の記録）

- 応用1（けしゴムと本が野外）：屋外でも成立する場面のため現状維持。教室に寄せる判断もあり得る。
- 基本 obj「それは、あなたの水とうかな？」：水とうは野外でも自然なため ground のまま（机版は「これ」側に既存）。
- 箱・ボール・花・ピン等の ground：野外の地面でも不自然でないため維持。
- 応用14（プリント）は既に classroom 指定で室内描画だった。

## 検証

- アプリ内蔵の validateQuestionBank()／validateAdv() が空（エラーなし）。
- Node のスタブ環境で、基本91問×左右反転×ヒント4段階＝728描画と、応用17場面×全会話行×反転×ヒント段階の全描画を実行し、例外・NaN・undefined がないことを確認。修正箇所は描画文字列でも検査した（ハサミが1つだけ、テーブルの存在、shade-tree の描画など）。
- リポジトリの scripts/qa-kosoado.cjs は作成者環境（Windows の Playwright/Edge）専用のため未実施。実機での目視確認は未実施。
