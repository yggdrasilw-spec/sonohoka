# 「なかまに なる ことば」と「和語・漢語・外来語」の敵対的レビュー

「なかまに なる ことば」は小学2年生の自力練習とベン図を使った授業提示、「和語・漢語・外来語」は小学5年生の授業提示と自力練習を想定した。添付の2ファイルから公開版を作成し、「なかまに なる ことば」は教材116のURLと学習記録の保存キーを引き継いだ。「和語・漢語・外来語」は教材120に掲載した。

## 検証範囲

- 教科内容・具体物と文の対応・学習順序・誤答支援は、語の分類、27場面の文への代入、3種のベン図、正解・誤答・再挑戦で確認。数量・縮尺、外部データ同期や権限の機能は対象外。
- 自力学習と授業操作は、表紙から各活動への導線、スライドの順送りと直接移動、ベン図の切り替え・再訪、結果・振り返りを確認。
- 操作と表示の回帰試験は `node scripts/qa-word-lessons.cjs`。公開環境は第1引数に GitHub Pages のベースURLを渡す。320×568、390×844、768×1024、1024×768、1280×720、568×320の Edge エミュレーションで、作品集の検索・絞り込み・画像・起動と両教材を確認する。90語の分類、27場面の全81選択、3種のベン図を網羅する。
- 音声は、ブラウザへの発話内容、消音、画面遷移後の発話取り消しをスタブで確認。学校端末・スマートフォンの実機、スクリーンリーダー、日本語音声の聞こえ方、授業での学習効果は未検証。
