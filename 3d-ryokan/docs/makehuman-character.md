# MakeHuman人物と動作の修正（2026-09-12）

## 変更

球・円柱の人物を、MakeHuman / MPFBから生成した指付きスキンメッシュに置き換えた。GLBは自己完結型で、実行時のCDNアクセスやBlenderは不要。

人物座標は上 +Y、正面 +Z、本人の右 -X。向きは顔・足先と合わせて確認した。歩行前に進行方向へ向き、机の前で机へ向き直る。接触前に手を開き、握ってから持ち上げ、机から下がってから見せる向きへ回る。

上腕・前腕長はモデルから取得し固定。手首の目標は可到達範囲へ制限し、届かない位置へ腕を伸長させない。肘の曲げ面へ上腕のひねりを合わせてから肘を曲げるため、肘で横方向のねじりが発生しない。膝にも同じ構造を適用。最大屈曲145度を教材用の制御上限とし、伸ばし切る特異姿勢を避ける。

掌・指の向きはモデルの中指と人差し指／小指の配置から計算。4指は掌側へ曲げ、親指は他の指へ向ける別軸を使用する。容器は側面を包み、大きい物は両手、本・紙は側面から持ち上げて下から支える。横から見る操作はカメラを動かし、物だけを手から回転させない。

## 表面のちらつき

旧モデルは白いページの箱と表紙の外面が同じ位置にあった。ページを内側へ収め、表紙と同じ面に重なる構造と不要な表面線を除去。公称の外寸は維持した。

MPFBのGLBが不透明な衣服まで半透明として出力したことによる三角形の描画順の乱れも、衣服を不透明、髪・眉をアルファテストにして修正。

## 再生成

リポジトリの隣の `.tools` に次を配置する。

- `blender-4.5.7-windows-x64/`：公式Windows ZIPを展開。`portable/` を作成。
- `mpfb2/`：上記の公式コミットを取得。
- `makehuman-assets/`：公式CC0素材集を展開。

親フォルダから実行：

```powershell
./.tools/blender-4.5.7-windows-x64/blender.exe --background --factory-startup --python 3d-ryokan/scripts/build-character.py
```

GLBと骨位置JSONは `app/models`、編集用Blendは `.tools/character-source.blend` へ保存。システムのBlender設定を変更しない。GLTFLoader / BufferGeometryUtils は同梱Three.jsと同じ0.169.0版で、インポート先のみローカル相対パスに変更。

## 検証

```powershell
node --test scripts/catalog.test.mjs scripts/units.test.mjs scripts/character.test.mjs
```

実際のGLBを読み込み、モデルの骨の長さ、手首の位置、人物の方向変更、肘の単軸屈曲、座位の骨盤位置、全物品の接触から提示までの到達可能性を検証する。

ブラウザの固定姿勢確認は `app/?qa=hold`、`?qa=hold&side=1`、`?qa=hold&item=encyclopedia`、`?qa=pickup&t=0.60&item=encyclopedia`、`?qa=bath&view=wide`。QAパラメータ時だけアニメーションを停止し、ページ末尾に関節座標を表示する。通常URLでは動作する。

## 現段階の限界

握りは物の寸法と種類に応じた設定で、全指の接触を物理計算で解く方式ではない。特に鉛筆や取っ手付き物品は専用の把持調整の余地がある。歩行・浴槽への移動は教材用の簡略動作。通常モードはTシャツとズボン、お風呂モードはMindfrontの既存水着 M_Swimming_trunks_02 を着用したモデルを表示する。体型は児童風の設定であり人体計測の標準値ではない。
