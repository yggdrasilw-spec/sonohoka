# 体型・歩行・図鑑の確認（2026-09-24）

身長は頭頂130cmを維持し、年齢入力を10歳相当の0.1875から8歳相当の7/48へ変更。頭部の縦横と奥行きを拡げ、頬・顎・目・口角を調整。服装版と水着版を同じ設定で再生成した。教材用のデザインで、児童の標準人体計測値ではない。

歩行はCMU Graphics Labの07_01をBruce HahneがBVHへ変換したデータから抽出。0.42〜1.52秒の足先・手首軌道を正規化し、記録時のドリフトを除去してループ化。移動距離78cmごとに1周期、児童の歩幅に合わせた足先IKと腕振りとして利用。開始・停止でブレンドし、把持中は腕振りを抑制する。成人の収録動作を調整したもので、児童の実測歩行ではない。物品の把持と浴槽をまたぐ動作は引き続き専用処理。浴槽移動時の過大な上方への跳ねを抑えたが、浴槽動作はモーションキャプチャーではない。

- 原データ: https://mocap.cs.cmu.edu/
- BVH取得元: https://github.com/una-dinosauria/cmu-mocap/blob/master/data/007/07_01.bvh

The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.

図鑑は幅216 × 高さ284 × 厚さ25mm。3Dモデルの包絡寸法とカタログ登録値を照合し、余分なスケールがないことを確認。高さは人物身長の約21.8%。近距離の手元カメラでは人物より前の本が遠近法で強調されるため、大きな物はカメラを1.3mまで引き、顔と上半身が比較できる構図へ変更した。図鑑自体の寸法は変更していない。寸法の根拠は既存カタログ文書を参照。

確認: Nodeの17テスト（全教材の寸法、手の到達、指、座位、水着、歩行ループと停止、単位換算）が成功。ブラウザで図鑑の保持と全身・歩行中の姿勢を確認。
