取得日：2026-09-25。GLB本体は配布ファイル。アプリ実行時に向きと一様スケール・位置を調整しています。
ゾウ全高3m、キリン全高5m、ワニ全長5m、クジラ全長30mの比較例です。原模型は形態を簡略化したもので、ワニをイリエワニ・クジラをシロナガスクジラとして種同定したものではありません。これらは該当種の長さの量感を一般的なワニ・クジラ模型で示しています。

寸法資料は各フィールドの「寸法の根拠と素材」を参照。動物の最大・平均・典型値を一律の値として扱わず、設定した比較例として表示しています。
